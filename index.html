1. त्रिकोणमितीय फलनों की मूलभूत परिभाषा (Definition of Trig Functions)

क) समकोण त्रिभुज पर आधारित

यदि 0 < θ < π/2 हो:

sin θ = लंब / कर्ण
cos θ = आधार / कर्ण
tan θ = लंब / आधार
csc θ = कर्ण / लंब
sec θ = कर्ण / आधार
cot θ = आधार / लंब

ख) इकाई वृत्त पर आधारित (Unit Circle)

त्रिज्या r = 1 वाले वृत्त पर कोई बिंदु (x, y):

sin θ = y / 1 = y
cos θ = x / 1 = x
tan θ = y / x
csc θ = 1 / y
sec θ = 1 / x
cot θ = x / y

2. फलनों के गुणधर्म: प्रांत (Domain), परिसर (Range) और आवर्तकाल (Period)

फलन (Function) प्रांत (Domain) परिसर (Range) आवर्तकाल (Period)
sin x R (सभी वास्तविक संख्याएँ) [-1, 1] 2π
cos x R [-1, 1] 2π
tan x R - {(2n+1)π/2 ; n ∈ Z} (-∞, ∞) π
csc x R - {nπ ; n ∈ Z} (-∞, -1] ∪ [1, ∞) 2π
sec x R - {(2n+1)π/2 ; n ∈ Z} (-∞, -1] ∪ [1, ∞) 2π
cot x R - {nπ ; n ∈ Z} (-∞, ∞) π
JEE आवर्तकाल नियम (Periodicity Shift): यदि किसी फलन f(x) का आवर्तकाल T है, तो f(ωx) का आवर्तकाल T / |ω| होगा।
उदाहरण: sin(ωx) → 2π/ω | cos(ωx) → 2π/ω | tan(ωx) → π/ω

3. मूलभूत सर्वसमिकाएँ (Basic Identities)

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ ⇒ sec²θ - tan²θ = 1
1 + cot²θ = csc²θ ⇒ csc²θ - cot²θ = 1
tan θ = sin θ / cos θ
csc θ = 1 / sin θ
sec θ = 1 / cos θ
cot θ = 1 / tan θ = cos θ / sin θ

4. सम/विषम फलन एवं आवर्ती गुण (Even/Odd & Periodic Properties)

सम/विषम फलन (Even / Odd)

sin(-θ) = -sin θ
cos(-θ) = cos θ (सम फलन)
tan(-θ) = -tan θ
csc(-θ) = -csc θ
sec(-θ) = sec θ (सम फलन)
cot(-θ) = -cot θ

आवर्ती नियम (जहाँ n ∈ Z पूर्णांक है)

sin(θ + 2nπ) = sin θ
cos(θ + 2nπ) = cos θ
tan(θ + nπ) = tan θ
csc(θ + 2nπ) = csc θ
sec(θ + 2nπ) = sec θ
cot(θ + nπ) = cot θ

5. कोणों के योग और अंतर के सूत्र (Sum & Difference Formulas)

sin(α ± β) = sinα cosβ ± cosα sinβ
cos(α ± β) = cosα cosβ ∓ sinα sinβ
tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)
cot(α ± β) = (cotα cotβ ∓ 1) / (cotβ ± cotα)

6. गुणज एवं उप-गुणज कोणों के सूत्र (Double & Half Angle Formulas)

द्विकोण सूत्र (Double Angle)

sin(2θ) = 2sinθ cosθ = 2tanθ / (1 + tan²θ)
cos(2θ) = cos²θ - sin²θ = 2cos²θ - 1
cos(2θ) = 1 - 2sin²θ = (1 - tan²θ) / (1 + tan²θ)
tan(2θ) = 2tanθ / (1 - tan²θ)

अर्ध-कोण सूत्र (Half Angle)

sin²θ = ½ (1 - cos(2θ))
cos²θ = ½ (1 + cos(2θ))
tan²θ = (1 - cos(2θ)) / (1 + cos(2θ))
sin(θ/2) = ±√[(1 - cosθ) / 2]

7. योग-अंतर एवं गुणनफल रूपांतरण (Product & Sum Identities)

गुणनफल से योग/अंतर

2 sinα cosβ = sin(α+β) + sin(α-β)
2 cosα sinβ = sin(α+β) - sin(α-β)
2 cosα cosβ = cos(α+β) + cos(α-β)
2 sinα sinβ = cos(α-β) - cos(α+β)

योग/अंतर से गुणनफल (C & D Formulas)

sin C + sin D = 2 sin((C+D)/2) cos((C-D)/2)
sin C - sin D = 2 cos((C+D)/2) sin((C-D)/2)
cos C + cos D = 2 cos((C+D)/2) cos((C-D)/2)
cos C - cos D = -2 sin((C+D)/2) sin((C-D)/2)

8. पूरक कोण सूत्र (Cofunction)

sin(π/2 - θ) = cosθ
cos(π/2 - θ) = sinθ
tan(π/2 - θ) = cotθ
cot(π/2 - θ) = tanθ
sec(π/2 - θ) = cscθ
csc(π/2 - θ) = secθ

9. डिग्री एवं रेडियन रूपांतरण

यदि D डिग्री में कोण है और R रेडियन में है:

D / 180 = R / π
R = (D × π) / 180
D = (R × 180) / π
