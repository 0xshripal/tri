1. त्रिकोणमितीय फलनों की परिभाषा (Definition of Trig Functions)

क) समकोण त्रिभुज परिभाषा

यदि 0 < θ < π/2 हो:

sin θ = लंब / कर्ण
cos θ = आधार / कर्ण
tan θ = लंब / आधार
csc θ = कर्ण / लंब
sec θ = कर्ण / आधार
cot θ = आधार / लंब

ख) इकाई वृत्त परिभाषा (Unit Circle)

त्रिज्या r = 1 वाले वृत्त पर कोई बिंदु (x, y):

sin θ = y / 1 = y
cos θ = x / 1 = x
tan θ = y / x
csc θ = 1 / y
sec θ = 1 / x
cot θ = x / y

2. फलनों के गुणधर्म: डोमेन, रेंज और आवर्तकाल (Facts & Properties)

फलन (Function) डोमेन (Domain) रेंज (Range) आवर्तकाल (Period)
sin x R (सभी वास्तविक संख्याएँ) [-1, 1] 2π
cos x R [-1, 1] 2π
tan x R - {(2n+1)π/2 ; n ∈ Z} (-∞, ∞) π
csc x R - {nπ ; n ∈ Z} (-∞, -1] ∪ [1, ∞) 2π
sec x R - {(2n+1)π/2 ; n ∈ Z} (-∞, -1] ∪ [1, ∞) 2π
cot x R - {nπ ; n ∈ Z} (-∞, ∞) π
JEE आवर्तकाल नियम (Periodicity Shift): यदि f(x) का आवर्तकाल T है, तो f(ωx) का आवर्तकाल T / |ω| होगा।
उदाहरण: sin(ωx) → 2π/ω | cos(ωx) → 2π/ω | tan(ωx) → π/ω

3. बुनियादी सर्वसमिकाएँ (Formulas and Identities)

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ ⇒ sec²θ - tan²θ = 1
1 + cot²θ = csc²θ ⇒ csc²θ - cot²θ = 1
tan θ = sin θ / cos θ
csc θ = 1 / sin θ
sec θ = 1 / cos θ
cot θ = 1 / tan θ = cos θ / sin θ

4. कोणों के नियम (Even/Odd & Periodic Formulas)

सम/विषम फलन (Even / Odd)

sin(-θ) = -sin θ
cos(-θ) = cos θ (सम फलन)
tan(-θ) = -tan θ
csc(-θ) = -csc θ
sec(-θ) = sec θ (सम फलन)
cot(-θ) = -cot θ

आवर्ती नियम (जहाँ n पूर्णांक है)

sin(θ + 2πn) = sin θ
cos(θ + 2πn) = cos θ
tan(θ + πn) = tan θ
csc(θ + 2πn) = csc θ
sec(θ + 2πn) = sec θ
cot(θ + πn) = cot θ

5. कोणों के योग और अंतर सूत्र (Sum and Difference Formulas)

sin(α ± β) = sinα cosβ ± cosα sinβ
cos(α ± β) = cosα cosβ ∓ sinα sinβ
tan(α ± β) = (tanα ± tanβ) / (1 ∓ tanα tanβ)

6. गुणित कोण और अर्ध-कोण सूत्र (Double & Half Angle Formulas)

द्विकोण सूत्र (Double Angle)

sin(2θ) = 2sinθcosθ = 2tanθ / (1+tan²θ)
cos(2θ) = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ
cos(2θ) = (1-tan²θ) / (1+tan²θ)
tan(2θ) = 2tanθ / (1-tan²θ)

अर्ध-कोण सूत्र (Half Angle)

sin²θ = ½ (1 - cos(2θ))
cos²θ = ½ (1 + cos(2θ))
tan²θ = (1 - cos(2θ)) / (1 + cos(2θ))

7. रूपांतरण सूत्र (Product & Sum Identities)

गुणनफल से योग/अंतर

sinα sinβ = ½ [cos(α-β) - cos(α+β)]
cosα cosβ = ½ [cos(α-β) + cos(α+β)]
sinα cosβ = ½ [sin(α+β) + sin(α-β)]

योग/अंतर से गुणनफल

sinα + sinβ = 2 sin((α+β)/2) cos((α-β)/2)
sinα - sinβ = 2 cos((α+β)/2) sin((α-β)/2)
cosα + cosβ = 2 cos((α+β)/2) cos((α-β)/2)
cosα - cosβ = -2 sin((α+β)/2) sin((α-β)/2)

8. सह-फलन और रूपांतरण नियम (Cofunction Formulas)

sin(π/2 - θ) = cosθ
cos(π/2 - θ) = sinθ
tan(π/2 - θ) = cotθ
csc(π/2 - θ) = secθ
sec(π/2 - θ) = cscθ
cot(π/2 - θ) = tanθ

9. डिग्री से रेडियन रूपांतरण (Degree to Radian)

यदि x डिग्री में कोण है और r रेडियन में है:

π / 180° = r / x
r = (π * x) / 180°
x = (180° * r) / π
